# SEO & Performance Strategy

## PageSpeed Goals
- Target: 92+ Score on Mobile PageSpeed Insights

## Core Guidelines
- Semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`)
- Single `<h1>` per page with hierarchical `<h2>`-`<h6>`
- Next.js Image Optimization with explicit width/height and WebP/AVIF formats
- Dynamic metadata, OpenGraph cards, JSON-LD Structured Data
- Automated `sitemap.ts` and `robots.ts`
